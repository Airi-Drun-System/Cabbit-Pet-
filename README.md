# Cabbit pet!

Тамагочи про кэббита. Весь проект лежит в корне репозитория, ничего собирать не нужно.

## Что где лежит

- `index.html` — сама игра
- `hero.png` — картинка кэббита, должна лежать рядом с index.html
- `manifest.webmanifest` — название, цвета и иконки приложения
- `sw.js` — чтобы игра открывалась без интернета
- `icons/` — иконки приложения
- `screenshots/` — скриншоты для карточки приложения

## Как выложить

1. Создай новый репозиторий и загрузи в него все файлы из архива (вместе с папкой `icons`).
2. Settings, затем Pages: Source — Deploy from a branch, ветка `main`, папка `/ (root)`, Save.
3. Через минуту игра будет по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.
4. Открой pwabuilder.com, вставь эту ссылку, нажми Start, затем Package For Stores и выбери Android. Иконки, название и скриншоты PWABuilder возьмёт из `manifest.webmanifest` сам.
